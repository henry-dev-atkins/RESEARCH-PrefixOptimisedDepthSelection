## Project Teaching Summary

### Philosophy

- PODS is a research repo, not a general-purpose product stack.
- The project prefers simple, config-driven experiment execution over ad hoc scripts or hidden behaviour.
- Experiments must fail loudly when the runtime is unsupported, especially around CUDA and GPU usage.
- Claims must be grounded in measured deployment cost, not theoretical FLOP reduction.
- Static prefix deployment is the core idea; dynamic early exit is explicitly out of scope unless stated otherwise.

### Core Goal

Train one deeper model whose prefixes are valid standalone deployable models, then select the shallowest prefix that satisfies a validation-quality target and a measured deployment-cost objective.

### Scientific Boundary

- The defensible claim is a measured static deployment frontier from one training run.
- The repo must compare against strong static baselines, especially independently trained shallow models and naive truncation.
- Mixed or negative outcomes are acceptable if measured honestly.

## Repo Reality

### Main Entrypoint

- `uv run python -m pods.run --config <config-path>`
- CLI loader: `pods/src/pods/run.py`

### Main Config Surface

- `pods/configs/sanity/`
- `pods/configs/cifar/`
- `pods/configs/glue/`
- Runtime schema: `pods/src/pods/config/schema.py`

### Main Run Flow

1. Load config in `pods/src/pods/run.py`.
2. Build datasets and train/selection/test loaders in `pods/src/pods/experiments/runner.py`.
3. Build the requested model via `pods/src/pods/models/registry.py`.
4. Train with `pods/src/pods/training/loops.py`.
5. Evaluate all relevant prefix depths with `pods/src/pods/eval/quality.py`.
6. Benchmark extracted prefixes with `pods/src/pods/eval/benchmark.py`.
7. Select the deployable depth with `pods/src/pods/eval/select.py`.
8. Persist raw run artefacts and regenerate processed summaries through `pods/src/pods/experiments/reporting.py` and `pods/src/pods/eval/summarise.py`.

### Main Output Paths

- Raw experiment outputs: `pods/results/raw/`
- Processed summaries: `pods/results/processed/`
- Local exploratory analysis: `temp/`
