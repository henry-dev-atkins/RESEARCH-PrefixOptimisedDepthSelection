## Bugs Found And Fixed

### Bug 1: snapshot round-trip failure for transformer configs

Symptom:

- first distilled proof run failed loading teacher config snapshot with:
  - `TypeError: 'NoneType' object is not iterable`

Cause:

- `load_config` treated presence of `input_shape` as meaning it was iterable
- transformer snapshots save `input_shape: null`

Fix:

- added `_optional_tuple(...)` handling and used it for `model.input_shape`

### Bug 2: historical BERT teacher checkpoint missing pooler weights

Symptom:

- second distilled proof attempt failed loading teacher checkpoint with missing:
  - `backbone.pooler.dense.weight`
  - `backbone.pooler.dense.bias`

Cause:

- historical saved teacher checkpoint does not include optional pooler parameters
- current `PodsBert` build path instantiates them

Fix:

- added `_load_checkpoint_with_allowed_missing(...)`
- allowed only the known BERT pooler gap for teacher loading
- all other checkpoint incompatibilities remain fatal
